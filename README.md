# PocketSmart AI - Smart Budget & Recommendation Assistant 💰

An AI Augmented Backend Application designed for smart financial management for students and beginners.

## 🎯 Project Summary
PocketSmart AI helps users track income, expenses, and get intelligent budget recommendations using Google Gemini AI.

## ✨ Features
- 🏠 Home Interior Planner - Room, style, budget based recommendations
- 🎉 Party Budget Planner - Smart cost split for catering, decoration, venue
- 💍 Jewelry Planner - Occasion based recommendations with AI
- 🔐 User Authentication - Secure login with JWT & bcrypt
- 📜 History - View past recommendations
- 📊 Dashboard - Central hub for all planners

## 🛠️ Tech Stack
- Backend: FastAPI (Python)
- AI: Google Gemini AI
- Frontend: Jinja2, HTML, CSS, JavaScript
- Database: SQLite
- Auth: JWT, passlib bcrypt
